# 매일영어 v0.2

아이의 영어 듣기 구간과 일일·주간 과제를 관리하는 브라우저 학습표입니다.

## 데이터 저장

- 학습 설정과 진도는 사용하는 브라우저에 저장됩니다.
- `이 기기에 오디오 저장`을 선택하면 오디오도 해당 브라우저에 저장됩니다.
- MP3와 JSON 백업 파일은 이 저장소에 포함되지 않습니다.
- 새 주소나 새 기기에서는 JSON 백업을 불러오고 오디오를 다시 연결해야 합니다.

## 실행

`index.html`을 정적 웹 서버에서 제공하면 됩니다.

```bash
python3 -m http.server 4173
```

브라우저에서 `http://127.0.0.1:4173/`을 엽니다.
